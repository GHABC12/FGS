
##  实验

### 实现细节

**任务与数据集。** 在六个代表性视觉任务上评估模型性能，涵盖 high-level 视觉理解到 low-level 图像处理，包括 NYUv2 上的深度估计、ADE20K 上的语义分割、COCO 上的全景分割、SIDD 上的图像去噪、合并去雨数据集 上的图像去雨、以及 LoL 上的低光图像增强。为评估分布偏移下的泛化能力，我们采用 中引入的 15 种常见损坏，每种损坏有 5 个严重度级别。为简化实验，我们主要在严重度级别 5 上报告结果，并使用两种设定：(i) **zero-shot** 设定，其中任务 prompt 来自训练分布（即干净图像）；(ii) **one-shot** 设定，其中任务 prompt 来自测试分布（即损坏图像）。

**基础模型。** 我们采用 Painter 作为 VICL 模型。Painter 基于 ViT-Large 架构 (~307M 参数)，包含 24 层 Transformer block，嵌入维度为 1024，16 个注意力头，MLP 比率为 4，patch 大小为 16×16。输入为四格网格状图像画布，每个子图像调整至 448×448。Painter 使用 MAE-style masked image modeling 在 7 个任务上联合预训练 15 个 epoch，学习率为 1e-3，等效 batch size 为 2048，使用 AdamW 优化器，权重衰减为 0.1，层级衰减为 0.8，梯度裁剪为 3。预训练从 MAE ViT-Large 权重初始化。

**VPT 配置。** 与原始 VICT 对完整 encoder 进行微调不同，当前项目采用 Visual Prompt Tuning (VPT) 策略。在 Painter 的 24 层 Transformer 中，选择 9 个候选层插入可学习的 prompt token: 浅层 (Layer 0, 1, 2)、中层 (Layer 10, 11, 12) 和深层 (Layer 21, 22, 23)。这些候选层被分为三个层组: Group 1 (浅层, Layer 0–2)、Group 2 (中层, Layer 10–12) 和 Group 3 (深层, Layer 21–23)。每个候选层分配一个独立的 prompt embedding，形状为 `(1, prompt_length, 1024)`。Prompt token 以正态分布 N(0, 1e-6) 初始化，并应用 dropout rate 0.1。在前向传播时，仅将当前激活层的 prompt token 拼接到对应 Transformer block 的图像 token 前方；若上一层存在 prompt token，则先剥离再拼接当前层 prompt。测试时优化的主体为这些 prompt token，而主干网络权重保持冻结。

**测试时优化。** 对于每个测试样本，我们首先将模型权重重置为预训练状态。在每步优化中，执行标准的 VICT cycle consistency 流程：(1) 使用原始四格画布预测测试输出，(2) 翻转角色，将预测的测试输出作为 prompt 重构原始任务 prompt 输出，(3) 使用 Smooth L1 loss 计算重构误差并通过反向传播更新参数。优化器为 AdamW，betas=(0.9, 0.999)，权重衰减为 0。与原始 VICT 在 60 步内以 lr=1e-6 优化完整 encoder 不同，当前项目仅更新获胜层组的 VPT prompt 参数（3 层的 prompt token），步数为 10 步，学习率根据任务和损坏类型在 1e-6 至 1.2e-4 之间调优。最终推理使用更新后的模型。

**频域校准 Prompt (FC-VICT)。** 当启用 FC-VICT 时，在将 prompt 图像输入模型之前对其进行频域校准，使其频谱分布更接近当前测试图像。具体而言：(1) 对 prompt 图像和测试图像分别做 2D FFT，提取幅度谱和相位谱；(2) 低频幅度使用混合权重 ρ 进行融合: A_L = (1−ρ)·A_prompt + ρ·A_test；(3) 高频幅度通过能量比例 α_H = mean(A_test·M_H) / mean(A_prompt·M_H) 进行校准，α_H 限制在 [α_min, α_max] = [0.5, 1.5]；(4) 中频幅度保持 prompt 原始值不变；(5) 相位始终保留 prompt 的相位；(6) 通过 IFFT 重建校准后的 prompt 图像。低频/高频的分界线由 r_L=0.03 和 r_H=0.15 定义。

**MFM 频域正则化。** 在 VICT cycle consistency loss 之上，添加频域正则化项。对重构的 support 图像和真实 support target 分别做 2D FFT (norm="forward")，计算复频谱差的幅度。随机选择低频遮罩 M_L 或高频遮罩 M_H（各 50% 概率），计算所选频带上的平均谱距离。总损失为 L = L_cycle + λ_f · L_freq。

**基于联合门控的层组选择。** 在对完整测试集进行推理之前，先在 10% 的测试样本上评估各候选层的适配潜力以选出最优层组。(1) **频域漂移分数**: 在干净数据上预先计算 9 个候选层 query token 频谱描述子（能量谱的对数归一化表示）的均值 μ 和标准差 σ 作为 anchor。对于每个损坏样本，提取其频谱描述子并计算标准化 L1 偏差 d_freq = mean(|e_test − μ| / (σ + ε))。(2) **梯度效用分数**: 激活所有 9 个候选层，执行一次 VICT cycle consistency 前向和反向传播，计算每层 prompt 梯度的 L2 范数，并转换为相对效用 d_util = ‖g_layer‖ / mean(‖g_all‖)。(3) 对两个分数分别进行 log 平滑、正值平移和 sum 归一化。(4) 融合分数 S = λ_gate · freq_score + (1−λ_gate) · util_score。(5) Softmax 加权并累加到层总分中。(6) 将所有样本处理后，按组汇总得分（group1 = layer0+1+2，group2 = layer10+11+12，group3 = layer21+22+23），选择得分最高的组作为全局胜出层组，后续所有测试图像共享该层组。

**对比方法。** 我们将所提出的方法与以下 baseline 进行对比: (i) **Painter (zero-shot)**: 冻结的 Painter 模型使用干净 prompt；(ii) **Painter (one-shot)**: 冻结的 Painter 模型使用损坏 prompt；(iii) **A1 (Prompt-only VICT)**: 仅使用 VPT + VICT cycle loss，禁用 FC-VICT (λ_f=0)、频域校准 (ρ=0) 和层组选择（始终使用 group2）；(iv) **A2 (无 FC-VICT)**: 在 A1 基础上保留层组选择，但禁用 FC-VICT 和 MFM；(v) **A3 (无 Group Selection)**: 在完整方法基础上去除层组选择；(vi) **Ours (Full)**: 完整方法，包含 VPT、FC-VICT、MFM 和联合门控层组选择。


###  消融研究

**VPT vs Full Encoder 微调。** 与原始 VICT 论文对完整 encoder 进行微调不同，当前项目采用 VPT 策略，仅优化少量 prompt token。VPT 的优势在于: (1) 参数量级更小 (每层 prompt token 约 100×1024 个参数 vs 完整 encoder 的 ~300M 参数)；(2) 优化更高效（通常 5–12 步即可收敛 vs 原始 VICT 的 60 步）；(3) 支持灵活的层组选择。当前实验在多个任务上验证了 VPT-based VICT 的有效性，部分任务上的结果与原始 VICT 论文报告的结果相当。

** 在 NYUv2-C 深度估计上的消融实验（使用 1/10 测试子集，seed=42）表明:
- **A1 (Prompt-only VICT)**: 不使用层组选择和 FC-VICT，始终使用 group1+2+3，平均 Abs.Rel 为 0.163/0.391（分别为zero-shot和one-shot）。
- **A2 (无 FC-VICT, 保留 Group Selection)**: 平均 Abs.Rel 降至 0.322/0.335，验证了层组选择的有效性。
- **A3 (无 Group Selection, 保留 FC-VICT)**: 平均 Abs.Rel 为 0.312/0.244，
- **完整方法 (FC-VICT + Group Selection)**: 通过联合门控机制融合频域漂移和梯度效用信息，进一步提升了适配效果。

**FC-VICT 消融。** 在 FC-VICT 模块的细粒度消融中:
- **B0 (原始 Prompt, A2 基线)**: 平均 Abs.Rel = 0.322/0.335。
- **B1 (低频替换, ρ=1.0)**: 将 prompt 低频完全替换为测试图像低频，平均 Abs.Rel 为0.358/0.387
- **B2 (低频软融合, α=1.0)**: 仅做低频混合而不做高频能量校准，平均 Abs.Rel 为0.316/0.360
- **B3 (仅高频校准, ρ=0)**: 仅调整高频能量，平均 Abs.Rel 为0.322/0.367。



**优化模块选择。** 当前项目默认仅优化 VPT prompt 参数，而主干网络权重始终保持冻结。这一设计基于原始 VICT 论文 Table 2 的消融结论——仅优化 encoder 与同时优化 encoder + decoder 表现几乎相同。

**调优策略。** 考虑到不同损坏类型之间存在显著差异，当前项目采用 per-corruption 调优策略。对于每个损坏类型，搜索最优的超参数组合，包括 prompt 学习率、优化步数、prompt 长度、频带数 (num_bands)、门控权重 (λ_gate)、MFM 正则化权重 (λ_f) 和低频混合权重 (ρ)。

## 方法伪代码 (当前项目 VPT-VICT + FC-VICT)

```python
# model: Painter with VPT
# theta_0: pre-trained weights
# prompt_embeddings: learnable VPT tokens for layers [0,1,2, 10,11,12, 21,22,23]
# anchor_stats: spectral μ, σ per layer from clean data

# === Stage 0: Anchor Statistics (offline, on clean data) ===
for clean_img in clean_sample_list:
    model.active_vpt_layers = []               # 不使用 VPT
    inter_feats = model(clean_input)
    for layer in [0,1,2,10,11,12,21,22,23]:
        e_hat = get_spectral_features(inter_feats[layer])  # FFT → 能量谱 → 对数归一化
        S_accum[layer].append(e_hat)
anchor_stats = {layer: {'mu': mean(S), 'std': std(S)} for layer}

# === Stage 1: Frequency-Calibrated Prompt (per test image) ===
if use_fc_vict:
    Ax, Px = abs_phase(FFT(prompt_img))        # prompt 幅度 + 相位
    At = abs(FFT(test_img))                     # 测试图像幅度
    A_L = (1-rho)*Ax + rho*At                   # 低频混合
    alpha_H = clamp(mean(At*M_H)/mean(Ax*M_H), 0.5, 1.5)  # 高频能量校准
    Af = M_L*A_L + M_M*Ax + M_H*alpha_H*Ax     # 组合幅度
    prompt_img = IFFT(polar(Af, Px))            # 保留 prompt 相位

# === Stage 2&3: Group Selection via Joint Gating (on 10% samples) ===
for sample in drift_sample_list:
    # 频域漂移分数
    model.active_vpt_layers = []
    inter_feats = model(sample)
    for layer in candidate_layers:
        e_test = get_spectral_features(inter_feats[layer])
        d_freq[layer] = mean(|e_test - anchor_stats[layer].mu| / anchor_stats[layer].std)

    # 梯度效用分数
    model.active_vpt_layers = candidate_layers   # 激活全部 9 层
    loss_cycle = VICT_cycle_consistency(model, sample)
    loss = loss_cycle + lambda_f * MFM_loss      # 如果开启 FC-VICT
    loss.backward()
    for layer in candidate_layers:
        d_util[layer] = norm(grad[layer]) / mean(all_norms)

    # 联合门控
    freq_scores = normalize(log(d_freq))
    util_scores = normalize(log(d_util))
    S[layer] = lambda_gate*freq_scores + (1-lambda_gate)*util_scores
    w = softmax(S)
    accumulate_scores(layer, w)

# 按组投票
group1_score = layer0 + layer1 + layer2
group2_score = layer10 + layer11 + layer12
group3_score = layer21 + layer22 + layer23
winner_group = argmax(group1_score, group2_score, group3_score)

# === Stage 4: Per-Image Adaptation & Inference ===
for x_t in test_loader:
    restore_to_pretrained_state()
    active_layers = group_mapping[winner_group]   # 仅激活 3 个胜出层

    for step in range(steps):
        y_t_pred = model((prompt_x, prompt_y, x_t, mask))
        y_pred = model((prompt_x, mask, x_t, y_t_pred))
        loss = SmoothL1(y_pred, prompt_y)
        if use_fc_vict:
            loss += lambda_f * MFM_loss(y_pred, prompt_y)
        loss.backward()
        optimizer.step()                           # AdamW, 仅更新 VPT prompt

    y_t_final = model((prompt_x, prompt_y, x_t, mask))  # 最终推理
    save(y_t_final)
```
